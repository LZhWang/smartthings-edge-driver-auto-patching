# Support

EdgeLoom is a pre-1.0 open-source project. Community questions and reports are
welcome, but support is provided on a best-effort basis.

## Choose the right channel

- **Usage and design questions:** start a
  [Q&A discussion](https://github.com/edgeloom-oss/edgeloom/discussions/categories/q-a).
- **Ideas and ecosystem proposals:** use
  [Ideas](https://github.com/edgeloom-oss/edgeloom/discussions/categories/ideas).
- **Reproducible bugs:** open a
  [bug report](https://github.com/edgeloom-oss/edgeloom/issues/new?template=bug_report.md).
- **Real-device results:** submit a
  [device report](https://github.com/edgeloom-oss/edgeloom/issues/new?template=device_report.yml),
  whether the result succeeded or failed.
- **Security vulnerabilities:** do not post publicly. Follow
  [SECURITY.md](SECURITY.md).

Before opening a new thread, search existing issues and discussions and include
the EdgeLoom version, operating system, Python version, command, and a minimal
reproduction when applicable. Remove access tokens, hub credentials, and the
generated `ha_devices.yaml` before posting logs.

We aim to triage actionable public reports within seven days. A triage response
may ask for more information, link a duplicate, identify a current limitation,
or accept the report for work. Security-report timelines are defined separately
in [SECURITY.md](SECURITY.md).

## Supported versions

Security support is limited to the versions listed in
[SECURITY.md](SECURITY.md). General questions about older releases are welcome,
but fixes normally target `main` and the next release.
